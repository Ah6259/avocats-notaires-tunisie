# Avocats et notaires Tunisie

Annuaire gratuit des avocats, notaires (عدول الإشهاد), huissiers de justice et traducteurs en Tunisie, par gouvernorat :
adresse, téléphone, itinéraire. En ligne : https://ah6259.github.io/avocats-notaires-tunisie/
Étiquettes OpenStreetMap : `office=lawyer`, `office=notary`, `office=bailiff`, `office=translator` (26 fiches au lancement).

# Annuaire gratuit (moteur commun)

Site statique (GitHub Pages) fabriqué à partir de `config.json` et des fiches de `donnees/`.

- Fiches : © les contributeurs d'OpenStreetMap (licence ODbL) et demandes des professionnels.
- Mise à jour chaque nuit par le robot GitHub (`.github/workflows/maj.yml`), sans intervention.
- Ajouter, corriger ou retirer une fiche : page « Professionnels » du site.

## Plan de continuité
Tout tourne sur GitHub : si personne n'intervient, le site continue d'être mis à jour chaque nuit. En cas de panne
d'OpenStreetMap, l'ancien fichier est gardé et GitHub prévient par e-mail.
